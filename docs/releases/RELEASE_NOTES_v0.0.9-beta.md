# 🐭 摩尔庄园HD 移动版 v0.0.9 beta · 新号存档不再丢 + 安卓全面屏铺满

> v0.0.8 发布后摩友反馈的问题修复版，**强烈建议所有新玩家更新**。覆盖 **macOS / Windows / Linux / Android** 四个平台的开箱即玩包，iOS 版同步到 v0.0.9 并通过 TestFlight 分发测试。

---

## 🚨 重要修复：新号存档被清空

**现象**：刚开的新号，还没盖几样东西时，**退出游戏再打开**，或者**点「好友」逛完特色庄园回家**，等级、摩尔豆、房子田地全部清零，变回 1 级新号。

- **根因**（技术向，可跳过）：原版存地图时，地图上物件不到 14 个就不存（`-[GameData saveMapData:]` 的物件数门槛）。联网时代注册新号会先存一份默认地图，所以没问题；离线没有注册这一步，新号在凑满 14 个物件之前一直没有地图档，下次读档读不到就按坏档处理、删档换新号。这个缺口离线版一直存在，v0.0.8 放开好友入口后更容易碰到。
- **修法**：照原版注册新号的流程，在读档前补存一份默认地图。等级、经验、摩尔豆都保留；还没存进地图档的新建筑会回到默认布局（与当年联网时一致）。
- 已经被清档的存档无法找回，抱歉。

## 📱 安卓：全面屏铺满，不再有两条大黑边

- 以前安卓版固定 4:3 显示，宽屏手机左右各留一条大黑边。现在和 iOS 一样**按手机屏幕比例铺满**：高度不变、视野横向扩展、不拉伸，弹框和菜单自动居中。4:3 的平板显示不变。
- iOS 的铺满适配早已在代码里，之前 TestFlight 上的旧包没有带上，这次的 TestFlight 新包已包含。

## 🌐 联网模式（私服玩家）

- **米米号支持 10 位 QQ 号**：账号界面可以输入 10 位米米号；大于 21 亿的米米号在资料栏、好友面板、换头像面板里不再显示成负数。
- **原版账号菜单两处闪退修复**：点「切换帐号」、登录后弹出欢迎界面时不再闪退。

## 🔍 正在排查

- 有安卓玩家反馈**升级后界面点不动**。电脑上按各种方式（逐级升级、一次连升十几级、宽屏模式）都没能复现，正在排查。如果你遇到了，请在**重新打开游戏之前**，把手机上的

## 📦 各平台下载与玩法

<details>
<summary>👉 <b>点击展开</b> —— macOS / Windows / Linux / Android 各平台下载与一键玩法</summary>

> 桌面三端均为**未签名**版本，首次启动时系统可能拦截，按下面步骤选择「信任 / 打开」即可，属正常现象。

### 🍎 macOS（Apple Silicon）

**下载：`MoleWorld_v0.0.9_beta_macOS_AArch64.zip`**

1. 解压 zip。
2. **右键**点击「摩尔庄园.app」→ 选择「**打开**」（请勿直接双击）。
3. 首次会弹出未签名提示，在弹窗里再点一次「**打开**」即可。

> 如果右键打开仍被拦截，可在终端执行：`xattr -dr com.apple.quarantine 摩尔庄园.app`

---

### 🪟 Windows（10 / 11 · 64 位）

**下载：`MoleWorld_v0.0.9_beta_Windows_X86_64.zip`** → 解压 → 双击 **`Run-MoleWorld.bat`** → 进游戏 🎮

---

### 🐧 Linux（64 位桌面）

**下载：`MoleWorld_v0.0.9_beta_Linux_X86_64.tar.gz`** → 解压进文件夹 → 双击 **`启动游戏.sh`**（GNOME 需右键「以程序运行」）→ 进游戏 🎮。需 OpenGL / SDL2 运行库。

---

### 🤖 Android（arm64）

**下载：`MoleWorld_v0.0.9_beta_Android_AArch64.apk`** → 直接覆盖安装 → 打开 App 直接进游戏 🎮

---

### 📱 iOS（arm64）

iOS 版基于纯 Rust 解释器后端（无需 JIT），通过 **TestFlight** 分发测试，不在本页提供下载。

</details>

### 🔁 从旧版本升级，存档怎么办

- **macOS / Android**：存档在系统的应用数据目录里，**直接覆盖安装 / 替换 .app 即可沿用**。
- **Windows / Linux**：存档在解压出来的游戏文件夹里（`touchHLE_sandbox` 文件夹）。解压到新文件夹后，把**旧文件夹里的 `touchHLE_sandbox` 复制到新文件夹**即可接着玩；或者直接解压覆盖到旧文件夹。

## ⚠️ 已知限制

以下内容属于**离线复活的天然限制**（原本依赖已关停的服务器），**并非 bug**：

- **离不开真实服务器的玩法**：好友互动与真人串门（推荐 / 访客格）、排行榜、米币、真实内购。离线会给原版的「需要联网」类提示，不会卡死、不丢数据。
- **其余季节联网活动**（爱丽丝、史莱克、火焰之战等）：美术当年运行时从服务器下载，本地不存在，离线多为空壳。
- **自拟数据**：活动表、脚印兑换表、折扣选品、公告正文、VIP 升级门槛、占卜奖池、离线每日任务选题规则为移植者自拟，非原版数据。
