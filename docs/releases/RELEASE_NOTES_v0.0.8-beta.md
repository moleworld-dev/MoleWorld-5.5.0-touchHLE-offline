# 🐭 摩尔庄园HD 移动版 v0.0.8 beta · 黄金岛离线复活 + 活动中心回归 + 宽屏适配 + 存档更安全

> 这是 v0.0.5 之后**四个月、两百多次提交**攒下的大版本（中间的 v0.0.6 / v0.0.7 没有公开发布，这次直接到 v0.0.8）。主线只有一条：**让离线时的表现和当年联网、服务器正常下发时一样**——能补全原版数据就补全，让原版逻辑自己跑，不绕开原版流程、不白送东西。
>
> 最大的几件事：**黄金岛（可建筑岛）离线完整复活**、**活动中心与各类日常活动回归**、**宽屏铺满适配**、**存档更安全**。覆盖 **macOS / Windows / Linux / Android** 四个平台的开箱即玩包，**iOS 版**同步到 v0.0.8 并通过 TestFlight 分发测试。

---

## 🏝️ 重磅：黄金岛离线完整复活

以前离线点黄金岛只会退回村庄，现在可以完整地玩：

- **进岛与默认岛**：新岛默认布局和原版一致（送 1 家水果店）；进出岛、开场剧情（中途打断下次补播）都按原版流程走。
- **岛上经营**：商铺经营与升级、餐厅、员工打工、食材下单、扩充土地、岛仓库收纳、飞鸟与增强道具。
- **咖啡馆许愿任务**：离线也能接，17 条做完照原版显示「暂时没有需要帮忙完成的心愿哦」，不会无限刷。
- **超级贝壳树**：点树弹面板、倒计时走完可收获，成长值跨会话保存。
- **探险船**：出海、返航、修船、领礼物，船不会再永久卡在海上。
- **岛任务与成就**：91 条岛任务链不再卡在第 4 条；岛成就累计跨会话保存，「卖出 100 份」类成就能解锁。
- **岛日常与岛商店限时折扣**离线照常下发；岛上沙滩 WC 的「左左右右」前三名会保存。
- **岛档落盘**：扣款、发奖、交任务、扩地、新放建筑后一帧内即时落盘；切后台、退出时再落一次；坏档会隔离并提示，不会用默认值把你的岛覆盖掉。

## 🎪 活动中心与日常活动回归

原本由服务器下发的数据，现在由**本机回环服务器**按原协议应答，原版界面原样可用：

- **活动中心**（双向翻页）、**每日签到（踩脚印）**、**脚印兑换**、**海底寻宝**（挖到海王贝可正常领奖）、**系统公告**、**限时折扣**、**每日任务**、**春节烟花**。
- **VIP 信息**：没充值的号也能正常打开 VIP 面板；首充大礼包照原版发放，岛上首充当场弹出。
- **占卜屋**：恢复原版「进门先取奖池」流程，水晶球里有奖品，**每天第一次免费**，之后每局扣 1 张占卜券；最后一个水晶球全是城堡部件。

> 说明：以上活动表、脚印兑换表、折扣选品、公告正文、VIP 升级门槛、占卜奖池等原版只存在服务器上，**为移植者自拟、非原版数据**，代码与游戏内均已标明；奖池不含贝壳，不能拿来刷贝壳。

## 🏡 主村

- **好友入口放开**：可进特色庄园逛丝尔特庄园，主线第 11 条「看看外面的世界!」不再卡死；推荐 / 访客等需要服务器的格子会给原版的连接错误提示。
- **每日任务**：离线时第 6 条固定为「拜访 1 个推荐好友」，去丝尔特庄园一趟就能完成。
- **读档自愈**：读档发现摩尔豆是负数按原版规则夹回 0。
- **安卓**：切后台改为挂起，回来停在原画面继续，不再退出重开；外接鼠标单击不再算两次、拖地图不再误判成双指缩放。

## 🖥️ 宽屏适配

- 可**铺满任意比例的屏幕**：高度不变、视野横向扩展，UI 弹框自动居中；17 张整屏底图换成宽版，小游戏触摸落点按原版坐标换算。
- 想要原汁原味的 4:3 也可以锁定比例。

## 💾 存档更安全

- **原子写盘 + 坏档隔离**：写到一半断电不会把存档写坏；读到坏档会改名留底，不再直接崩溃。
- **主档自动保留上一代好档**：主村存档（userinfo.dat / map.dat）每次覆盖前留一份上一代，启动时发现按原版判据坏了就**自动换回**（原版这时会删档换新号）。
- **同一存档只允许开一个游戏**：再次启动会提示「已经在运行」后退出，杜绝两个窗口互相覆盖存档。
- **退出前一定先存档**：关窗、切后台之外，**关掉启动它的终端**、**Windows 注销或关机**时也会先存档再退出。
- 修改器的「时间旅行」期间不会把未来的时间戳写进存档。

## 🎛️ 修改器（按 T）

- 新增**开发工具页**：时间旅行、各类任务跳转、岛档快进、**按经验值重算等级**（修复旧版「等级=N」写进存档的假等级）、重算工人 / 房间等。
- 开关语义全面校正：「全物品解锁」改名**「解除购买门槛」**——只放开等级 / VIP / 前置门槛，钱不够照样提示；「等级=N」「强制 VIP」「工人补满」只影响显示与门槛，不再写进存档。
- 危险操作二次确认，删档会全部删完才退出、失败原样写回。
- 物品还在摆放时，菜单不再能召唤小游戏（占卜奖品不会被冲掉）。

## ⚙️ 引擎（touchHLE）

- **同步上游 touchHLE v0.3.0**（dynarmic 一并升级）。
- 系统弹框可见可点；补齐表格、手势、翻页、滚轮捏合缩放；留言板、漂流瓶、好友留言能打字；字体缺字形时回退思源黑体。
- 默认简体中文（英文系统下任务剧情不再到头）、默认北京时间。
- 大量 Foundation / UIKit / 音频 / 图形补全，以前会直接崩溃的边角情况改为报错或安全跳过。
- **Windows 版改为图形程序**：双击 `Run-MoleWorld.bat` 后不再留一个黑色控制台窗口（以前点它的关闭按钮会不存档直接结束游戏）；出错时有弹窗，日志照写 `touchHLE_log.txt`。

## 📦 各平台下载与玩法

<details>
<summary>👉 <b>点击展开</b> —— macOS / Windows / Linux / Android 各平台下载与一键玩法</summary>

> 桌面三端均为**未签名**版本，首次启动时系统可能拦截，按下面步骤选择「信任 / 打开」即可，属正常现象。

### 🍎 macOS（Apple Silicon）

**下载：`MoleWorld_v0.0.8_beta_macOS_AArch64.zip`**

1. 解压 zip。
2. **右键**点击「摩尔庄园.app」→ 选择「**打开**」（请勿直接双击）。
3. 首次会弹出未签名提示，在弹窗里再点一次「**打开**」即可。

> 如果右键打开仍被拦截，可在终端执行：`xattr -dr com.apple.quarantine 摩尔庄园.app`

---

### 🪟 Windows（10 / 11 · 64 位）

**下载：`MoleWorld_v0.0.8_beta_Windows_X86_64.zip`** → 解压 → 双击 **`Run-MoleWorld.bat`** → 进游戏 🎮

---

### 🐧 Linux（64 位桌面）

**下载：`MoleWorld_v0.0.8_beta_Linux_X86_64.tar.gz`** → 解压进文件夹 → 双击 **`启动游戏.sh`**（GNOME 需右键「以程序运行」）→ 进游戏 🎮。需 OpenGL / SDL2 运行库。

---

### 🤖 Android（arm64）

**下载：`MoleWorld_v0.0.8_beta_Android_AArch64.apk`** → 直接覆盖安装 → 打开 App 直接进游戏 🎮

---

### 📱 iOS（arm64）

iOS 版基于纯 Rust 解释器后端（无需 JIT），通过 **TestFlight** 分发测试，不在本页提供下载。

</details>

### 🔁 从旧版本升级，存档怎么办

- **macOS / Android**：存档在系统的应用数据目录里，**直接覆盖安装 / 替换 .app 即可沿用**。
- **Windows / Linux**：存档在解压出来的游戏文件夹里（`touchHLE_sandbox` 文件夹）。解压到新文件夹后，把**旧文件夹里的 `touchHLE_sandbox` 复制到新文件夹**即可接着玩；或者直接解压覆盖到旧文件夹。

## ⚠️ 已知限制

以下内容属于**离线复活的天然限制**（原本依赖已关停的服务器），**并非 bug**：

- **离不开真实服务器的玩法**：好友互动与真人串门（推荐 / 访客格）、排行榜、米币、真实内购。离线会给原版的「需要联网」类提示，不会卡死、不丢数据。
- **其余季节联网活动**（爱丽丝、史莱克、火焰之战等）：美术当年运行时从服务器下载，本地不存在，离线多为空壳。
- **自拟数据**：活动表、脚印兑换表、折扣选品、公告正文、VIP 升级门槛、占卜奖池、离线每日任务选题规则为移植者自拟，非原版数据。
